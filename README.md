# MallenomTest

**Тестовое задание для .NET Core C# программиста**
**Цель задания:** выявить текущие навыки и знания работы в среде .NET Core и языка
программирования C#.

Требуется реализовать функционал простейшего Desktop и Web- API-приложения.

**Основные требования:**
⎯ Платформа разработки .NET Core 9.0.
⎯ Язык программирования С# 13.
⎯ База данных на выбор: Microsoft SQL Server, PostgreSQL.

Требования для построения Desktop и Web-API -приложения:
⎯ WPF или Avalonia UI – для Desktop-приложения.
⎯ ASP.NET Core – для Web-API-приложения.
Приложение должно состоять из двух программ: сервис API и Desktop-приложения.
