# MallenomTest

<br>**Тестовое задание для .NET Core C# программиста**
<br>**Цель задания:** выявить текущие навыки и знания работы в среде .NET Core и языка программирования C#.
<br>Требуется реализовать функционал простейшего Desktop и Web- API-приложения.

<br>**Основные требования:**
<br>⎯ Платформа разработки .NET Core 9.0.
<br>⎯ Язык программирования С# 13.
<br>⎯ База данных на выбор: Microsoft SQL Server, PostgreSQL.

<br>Требования для построения Desktop и Web-API -приложения:
<br>⎯ WPF или Avalonia UI – для Desktop-приложения.
<br>⎯ ASP.NET Core – для Web-API-приложения.

<br>Приложение должно состоять из двух программ: сервис API и Desktop-приложения.
